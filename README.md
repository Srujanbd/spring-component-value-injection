# Spring Core - @Component Value Injection

This repository demonstrates **Value Injection using the `@Component` annotation** in the Spring Framework. It showcases how Spring automatically detects and manages beans using annotation-based configuration while injecting values into bean properties.

## 📖 Overview

The `@Component` annotation marks a Java class as a Spring-managed bean. Combined with `@Value`, it allows primitive values and strings to be injected into bean fields, setter methods, or constructors without requiring XML configuration.

## 🚀 Concepts Covered

- Using the `@Component` annotation
- Injecting values with `@Value`
- Annotation-Based Configuration
